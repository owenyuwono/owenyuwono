| [poseidon](https://github.com/owenyuwono/poseidon) | Real-time FFT ocean entirely on GPU: Tessendorf spectrum synthesis, compute-shader IFFT per frame, no CPU round-trip. | `WebGPU` `TSL` `Three.js` `FFT` |

| [tiamat](https://github.com/owenyuwono/tiamat) | Smoothed-particle hydrodynamics: density and pressure resolve from kernel-weighted neighbors, so splashes fall out of the solver. | `SPH` `fluid simulation` `particles` |
| [gaia](https://github.com/owenyuwono/gaia) | Procedural grass rendered in the browser, fully deterministic. A seed reproduces the same field anywhere, no baked assets. | `Three.js` `deterministic` |
| [dryad](https://github.com/owenyuwono/dryad) | Trees grown from planet physics and a seed. Structure follows simulated conditions, so parameters change the growth. | `Three.js` `simulation` |
| [apate](https://github.com/owenyuwono/apate) | Small learning repo for surface detail that isn't there: parallax occlusion mapping, its silhouette-clipped variant, and displacement. | `POM` `SPOM` `displacement` |
