### [poseidon](https://github.com/owenyuwono/poseidon)

Real-time FFT ocean running entirely on the GPU. Tessendorf spectrum synthesis in frequency space, a compute-shader IFFT per frame, displacement and normals generated on device with no CPU round-trip.

`WebGPU` `TSL` `Three.js` `compute shaders` `FFT`

### [minos](https://github.com/owenyuwono/minos)

Custom engine in Rust and Vulkan with Nanite-style virtualized geometry: per-cluster LOD, GPU-side culling, software raster for sub-pixel triangles. Plus tectonic planets, streamed voxel terrain, FFT ocean.

`Rust` `Vulkan` `virtualized geometry` `GPU-driven culling` `voxel terrain`

### [demiurge](https://github.com/owenyuwono/demiurge)

Procedural planet generated from physics, continuous from orbit to ground. Simulated tectonics drive uplift, uplift drives stream-power erosion, erosion and latitude drive climate, and climate drives biomes.

`TypeScript` `WebGPU` `Three.js` `procedural generation` `simulation`

### [tiamat](https://github.com/owenyuwono/tiamat)

Fluid dynamics with smoothed-particle hydrodynamics. Density and pressure resolve from kernel-weighted neighbors each step, so free surfaces and splashes fall out of the solver instead of being faked.

`SPH` `fluid simulation` `particle systems`

### [gaia](https://github.com/owenyuwono/gaia)

Procedural grass generated and rendered in the browser. Fully deterministic, so a seed reproduces the same field on every machine, with no baked assets to ship.

`Three.js` `procedural generation` `deterministic`

### [dryad](https://github.com/owenyuwono/dryad)

Trees grown procedurally from planet physics and a seed. Structure follows the simulated conditions, so the same generator produces different growth under different planetary parameters.

`Three.js` `procedural generation` `simulation`
