# Owen Yuwono

Engineer working across distributed backend systems, real-time graphics and simulation, and blockchain infrastructure.

## Repositories

**[poseidon](https://github.com/owenyuwono/poseidon)**
GPU-driven real-time FFT ocean in Three.js with WebGPU/TSL. Tessendorf spectrum synthesis, compute-shader IFFT, displacement and normals generated on GPU.

**[minos](https://github.com/owenyuwono/minos)**
Rust and Vulkan engine with Nanite-style virtualized geometry: cluster LOD, GPU-driven culling, software rasterization for sub-pixel triangles. Also tectonic procedural planet generation, on-demand voxel terrain, and an FFT ocean.

**[gaia](https://github.com/owenyuwono/gaia)**
Deterministic procedural grass generation and rendering in the browser.

**[dryad](https://github.com/owenyuwono/dryad)**
Procedurally generated trees grown from planet physics and a seed.
